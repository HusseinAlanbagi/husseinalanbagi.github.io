Dynare saves it as yourmodel/Output/yourmodel_results.mat. Your file never leaves this browser.

Where is the file? After stoch_simul, Dynare saves yourmodel_results.mat in yourmodel/Output/ (Dynare 5 and later) or next to your .mod file (older versions). Add several files to compare models.

File won't load? Run this in MATLAB right after Dynare. It writes irfs.csv, which you can add instead:

% Export Dynare IRFs for the IRF Plotter
names = {}; data = [];
for j = 1:M_.exo_nbr
  for i = 1:M_.endo_nbr
    f = [M_.endo_names{i} '_' M_.exo_names{j}];
    if isfield(oo_.irfs, f)
      names{end+1} = [M_.endo_names{i} ':' M_.exo_names{j}];
      data(:, end+1) = oo_.irfs.(f)(:);
    end
  end
end
writecell(names, 'irfs.csv');
writematrix(data, 'irfs.csv', 'WriteMode', 'append');
