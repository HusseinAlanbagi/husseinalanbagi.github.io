📈 IRF Plotter for Dynare

Load your Dynare results, design the figures visually, and get LaTeX (pgfplots) code or images. Everything stays in your browser.

Equation editor ↗
1 · Load IRFs
Drop your yourmodel_results.mat here (or click to choose) — you can add several files to compare models.
Dynare writes it next to your .mod file, e.g. nk_model/Output/nk_model_results.mat (Dynare 5+) or nk_model_results.mat. A CSV from the snippet below also works.
No .mat file, or it won't load? Export a CSV from MATLAB instead

Run this in MATLAB right after Dynare (while oo_ and M_ are in the workspace). It writes irfs.csv in the current folder:

% Export Dynare IRFs for the IRF Plotter
names = {}; data = [];
for j = 1:M_.exo_nbr
  for i = 1:M_.endo_nbr
    f = [M_.endo_names{i} '_' M_.exo_names{j}];
    if isfield(oo_.irfs, f)
      names{end+1} = [M_.endo_names{i} ':' M_.exo_names{j}];
      data(:, end+1) = oo_.irfs.(f)(:);
    end
  end
end
writecell(names, 'irfs.csv');
writematrix(data, 'irfs.csv', 'WriteMode', 'append');

If you saved the results yourself with -v7.3, re-save with save('file.mat','oo_','M_','options_','-v7') — the v7.3 format can't be read in a browser.

2 · Design figures
Load a results file (or try the example data) to start.

One figure per shock is created for you. To combine shocks, add more lines to a figure (or use ＋ New).

Paper settings

Text width

Only affects the preview size; the LaTeX code always uses your document's \linewidth.

In your preamble: \usepackage{pgfplots} \usepgfplotslibrary{groupplots} \pgfplotsset{compat=1.18}. Legends use \ref{…}, so they appear after the second compile (Overleaf does this automatically). For many figures, separate CSV files keep your .tex short and compile faster.

The PDF is vector (sharp at any size) — use it with \includegraphics. Images are drawn at the preview's size and fonts, which match LaTeX's Computer Modern.

All figures in one go, each in its own figure environment (data inside the code).
