# Adding and removing features

Every optional feature of StochaTeX is a module: one JavaScript file in the `modules/` folder.

## Switch a feature on or off

Open **⚙ Features**. Each module has a switch. A module that is off registers nothing: no buttons,
no panels, no shortcuts. Your choices are remembered in this browser.

## Add a feature

Two ways:

1. **Without touching the site:** ⚙ Features → **Add a module file…** and choose a `.js` file.
   It is stored in this browser only, and can be removed from the same dialog.
2. **For everyone who uses your copy:** put the file in `modules/` and add its name to
   `modules/index.json`.

## Remove a feature for good

Delete its file from `modules/` and its name from `modules/index.json`. Nothing else refers to it.
(`irf-figures.js` uses one helper from `dynare.js`, so keep `dynare.js` if you keep that one.)

## Write a module

```js
export default {
  id: 'hello',                      // unique
  name: 'Hello',
  description: 'Shown in the Features dialog.',
  category: 'Writing',              // heading in the Features dialog
  defaultEnabled: true,
  activate(ctx) {
    ctx.ui.addToolbarButton({ label: 'Hello', onClick: () => ctx.editor.insert('Hello, world.') });
    ctx.on('compile', (result) => console.log('compiled:', result.success));
  },
};
```

Everything registered through `ctx` is removed automatically when the module is switched off.

| `ctx` part | What it gives you |
|---|---|
| `ctx.editor` | `getText()`, `getSelection()`, `getCursor()`, `insert(text)`, `replaceRange(from, to, text)`, `insertSnippet(template)`, `gotoLine(n)`, `addKeymap([...])`, `addCompletionSource(fn)`, `addExtension(ext)`; `ctx.cm` holds the CodeMirror classes |
| `ctx.project` | `files()`, `read(path)`, `write(path, content)`, `remove(path)`, `rename(a, b)`, `open(path)`, `exists(path)`, `isText(path)`, `mainFile`, `activeFile` |
| `ctx.ui` | `addToolbarButton({ label, icon, onClick, where })` (`where: 'top'` for the top bar), `addEditorButton(element)`, `addPanel({ id, title, icon, render })` (side bar, reached from the rail), `openDock({ title, body })` (strip under the source), `icon(name)`, `addStatusItem`, `addCommand` (command list), `modal`, `menu`, `toast`, `confirm`, `prompt`, `pickFiles`, `download` |
| `ctx.problems` | `set([{ file, line, severity, message }])`, `clear()`: entries for the Problems list |
| `ctx.compile` | `run()`, `last()` |
| `ctx.pdf`, `ctx.goto(file, line)` | the preview, and jumping to a source line |
| `ctx.on(name, fn)` | events: `change`, `cursor`, `open`, `files`, `project`, `compile`, `modules` |
| `ctx.settings` | `get(key, fallback)`, `set(key, value)`: remembered per module |
| `ctx.h(tag, attrs, ...children)` | small helper to build page elements |

The built-in modules are short and make good starting points: `word-count.js` (a status item),
`outline.js` (a side panel), `snippets.js` (a menu), `model-checks.js` (entries in the Problems list),
`equation-editor.js` (a dock), `proofread.js` (underlines with fixes).
